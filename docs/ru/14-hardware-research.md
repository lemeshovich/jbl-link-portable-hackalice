# Заметки по исследованию железа

[English](../en/14-hardware-research.md) · [Українська](../uk/14-hardware-research.md) · **Русский**

Заметки для тех, кто хочет пойти дальше, например заменить Алису локальным
голосовым стеком. Ничего из этого текущая конфигурация не использует.

## Микрофоны

- Устройство записи `hw:0,1` (Wake on Voice, `pcmC0D1c`), `S32_LE`, 16000 Гц, два
  канала, period 1000, buffer 8000.
- Его держит открытым `maind`, поэтому другая программа не может записывать, пока
  работает квазар.

## Петля воспроизведения

- `hw:0,5` (AWB_Record) записывает то, что воспроизводит колонка, а не микрофоны.
  Полезно, чтобы записать вывод или как опорный сигнал для подавления эха.

## Регуляторы громкости

| Регулятор | numid | Диапазон | Примечания |
|---|---|---|---|
| `Master` | 128 | от 0 до 999 | softvol, его двигают кнопки |
| `ShadowMaster` | 120 | от 0 до 999 | softvol для `default`, голос Алисы |
| `Digital Playback Volume` | 18 | от 0 до 255 | по умолчанию `207,207` |
| `HW Gain1 Volume` | 7 | в норме 524288 | устанавливает Linkplay при старте; см. [07](07-audio.md) |

## Светодиоды

В `/sys/class/leds/` есть `power-white`, `red`, `white1`…`white5` и `wifi`.
`white1`…`white5` — это **индикатор заряда сзади**, а не кольцо спереди.

Передним кольцом (фиолетовое, когда Алиса слушает, крутится, когда думает, синее
для Bluetooth, красное при выключенных микрофонах) управляет сам квазар через
`/dev/i2c-led`, который держит открытым `maind`. Его протокол неизвестен, и
IPC-сообщения для управления им нет; единственное сообщение `QuasarMessage` про
светодиоды, `led_screen_command` (180), предназначено для захвата экрана. Писать в
устройство параллельно с квазаром — риск сбить его состояние.

## Linkplay

`linkplay.sh` настраивает маршрутизацию кодека через `amixer` (переключатели вроде
`O03 I05`, `I2S O03_O04`, `AmpSwitch`), а затем запускает `rootApp`. Повторный
запуск только этих строк `amixer` **не** возвращает звук; усиление позже задаёт
сам старт Linkplay.
