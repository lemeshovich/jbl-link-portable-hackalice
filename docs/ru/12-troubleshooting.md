# Если что-то пошло не так

[English](../en/12-troubleshooting.md) · [Українська](../uk/12-troubleshooting.md) · **Русский**

## Звука нет совсем, Алиса тоже молчит

Чаще всего это сброшенное усиление кодека
([раздел 07](07-audio.md#коварное-усиление-после-загрузки)).

```
amixer -c 0 cget numid=7 | grep "  : values="      # 524288 — норма, 64 — проблема
/data/ytm/bin/ipcclean dmix
systemctl restart linkplay.service                  # прозвучит сигнал JBL
```

Если это повторяется после каждой загрузки, значит, что-то до сих пор обращается
к `Master` через `amixer sget` или `sset`.

## Bluetooth молчит, а Алиса говорит

Зависли подключения к `dmix`. Помогают те же две команды, что выше.

## Алиса «думает» без конца

Светодиоды крутятся, на «Алиса» она не реагирует, музыка приглушена. Значит,
ответ убрали, а диалог до сих пор его ждёт:

```
/data/ytm/bin/alicesay ""
```

## Алиса слушает без конца

Светодиоды горят, как во время прослушивания:

```
/data/ytm/bin/alicesay ""; sleep 2; /data/ytm/bin/qcancel -f 170 -E
```

Не помогло — перезапустите только голосовую роль:

```
kill $(ps | grep "[m]aind --yiod" | awk '{print $1}')
```

`quasar_launcher2` поднимет её за несколько секунд. Только не делайте этого раз
за разом: после нескольких падений подряд лаунчер откладывает роль примерно на
десять минут.

## Голосовые команды ведут себя странно

Сначала смотрим журнал — в нём каждое изменение состояния и каждое действие:

```
cat /tmp/ytm-voice.log
grep -E "wake word|intercepted|announce|speech sent|not picked up|restored" /tmp/ytm-voice.log
```

Потом `yiod.log` за то же время, пока его не перезаписало (а это считаные
минуты):

```
grep -a "HH:MM:S" /data/quasar/daemons_logs/yiod.log*
```

## ytm-alice просит войти после перезагрузки

`droproot_setup` поменял права на файл сессии, а ytm-alice принимает только 600.
Юнит, который ставит `30-ytm.sh`, исправляет это перед каждым запуском, так что
проверьте, на месте ли хук.

## Команды в PuTTY

- Кириллица, вставленная в PuTTY, может прийти испорченной, а некоторые символы
  ещё и запускают автодополнение. Пишите команды латиницей — именно поэтому
  «Включаю» зашито в `alicesay`.
- Если вставить две длинные команды подряд, они склеиваются. Перед следующей
  дождитесь приглашения оболочки.

## llm-alice

- Журнал — `/tmp/llm-alice.log`. В нём каждая обработанная фраза, каждый ответ,
  какая модель его дала и каким сценарием Алиса его прочитала.
- `llm-alice ask` без аргументов проверяет ключ и сеть, не задействуя голос.
- Если через несколько секунд Алиса говорит «Нейросеть сейчас не отвечает»,
  модель не ответила даже после повторов. Причину ищите в журнале; чаще всего это
  HTTP 503 — модель перегружена.
- Как решается, кому отвечать, — в [разделе 14](14-llm-alice.md).

## Как всё выключить

```
chattr -R -i /data/jbl-autostart
touch /data/jbl-autostart/ytm-off       # ytm-alice больше не стартует при загрузке
touch /data/jbl-autostart/llm-off       # llm-alice тоже
chattr -R +i /data/jbl-autostart
```

Остановить прямо сейчас: `systemctl stop ytm-alice.service` или
`systemctl stop llm-alice.service`.
