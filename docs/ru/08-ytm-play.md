# ytm-play

[English](../en/08-ytm-play.md) · [Українська](../uk/08-ytm-play.md) · **Русский**

Небольшой AAC-плеер для этой колонки, написанный потому, что прошивка не умеет
декодировать то, что отдаёт YouTube Music ([07](07-audio.md#что-прошивка-не-умеет-декодировать)).
Исходники: [ytm-play/ytm-play.c](../../ytm-play/ytm-play.c). Лицензия: GPL-2.0, так
как в него вкомпилирован faad2.

## Что он делает

```
http:// stream or local file ─► MP4 parser ─► faad2 (AAC) ─► ALSA (via dlopen)
```

- Вход: обычный URL `http://` или локальный файл. ytm-alice подаёт ему аудио из
  локального ретранслятора на `127.0.0.1:18883`, поэтому TLS в плеере не нужен.
- MP4: обычные файлы (`moov` перед `mdat`) и фрагментированные (`moof` с `mdat`;
  другие блоки, например `sidx`, пропускаются).
- Декодирование: faad2, собранный **без** флага DRM и скомпонованный статически.
- Вывод: `libasound.so` загружается через `dlopen`, поэтому бинарник не зависит от
  заголовков ALSA прошивки или точной версии библиотеки. Устройство задаётся `-D`
  (на колонке — `ytmout`).

## Интерфейс для ytm-alice

```
ytm-play [-v] [-g 0..100] [-D alsa-device] <url|file>
```

Стандартный ввод, по одной команде в строке:

| Команда | Действие |
|---|---|
| `pause` / `resume` | пауза или продолжение |
| `volume <0..1>` | программное усиление, чтобы приглушать музыку, пока говорит Алиса |
| `stop` | остановиться и выйти |

Стандартный вывод, по одному объекту JSON в строке: `{"event":"playing"}`,
`paused`, `position`, `eos`, `error`.

`-g 0` воспроизводит беззвучно — удобно, чтобы проверить устройство, ничего не
слыша.

## Корректное завершение

- Обработчик сигнала сразу закрывает сетевой сокет, поэтому чтение, зависшее на
  застопорившемся потоке, не держит процесс живым.
- Обработчик `atexit` доигрывает и закрывает PCM, поэтому слот `dmix`
  освобождается (см. [зависшие подключения](07-audio.md#зависшие-подключения-dmix)).

## Сборка

[ytm-play/build.sh](../../ytm-play/build.sh): Zig 0.17.0 под
`arm-linux-gnueabihf.2.27` и Cortex-A35, faad2 на коммите
`a335040022e14ff9b6c54bbd459590d4c7edffe8`, без символов и сжатый UPX 4.2.2.
Результат побайтово совпадает с бинарником из релиза.
