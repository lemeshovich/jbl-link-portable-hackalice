## Звука нет совсем, Алиса тоже молчит

Чаще всего сбросилось усиление кодека ([07](07-audio.md#ошибка-с-усилением-после-загрузки)).

```
amixer -c 0 cget numid=7 | grep "  : values="      # 524288 — норма, 64 — проблема
/data/ytm/bin/ipcclean dmix
systemctl restart linkplay.service                  # звучит сигнал JBL
```

Если это происходит после каждой загрузки, что-то до сих пор использует
`amixer sget` или `sset` для простого элемента `Master`.

## Bluetooth молчит, Алиса в порядке

Зависшие подключения `dmix`. Те же две команды, что выше.

## Алиса бесконечно «думает»

Светодиоды крутятся, слово активации игнорируется, музыка приглушена. Ответ
отбросили, а диалог его ждёт:

```
/data/ytm/bin/alicesay ""
```

## Алиса бесконечно слушает

Светодиоды горят, как во время прослушивания:

```
/data/ytm/bin/alicesay ""; sleep 2; /data/ytm/bin/qcancel -f 170 -E
```

Если всё ещё зависла, перезапустите только голосовую роль:

```
kill $(ps | grep "[m]aind --yiod" | awk '{print $1}')
```

`quasar_launcher2` поднимет её за несколько секунд. Не убивайте её раз за разом:
несколько падений подряд отправляют роль на карантин примерно на десять минут.

## Голосовые команды ведут себя странно

Сначала журнал — в нём видно каждое изменение состояния и каждое действие:

```
cat /tmp/ytm-voice.log
grep -E "wake word|intercepted|announce|speech sent|not picked up|restored" /tmp/ytm-voice.log
```

Затем `yiod.log` за то же время, пока он не ротировался (минуты):

```
grep -a "HH:MM:S" /data/quasar/daemons_logs/yiod.log*
```

## ytm-alice просит войти после перезагрузки

`droproot_setup` сбросил права на файл сессии на отличные от 600. Юнит из
`30-ytm.sh` исправляет это перед каждым запуском; проверьте, что хук установлен.

## Копирование команд в PuTTY

- Кириллица, вставленная в PuTTY, может прийти искажённой, а некоторые символы
  вызывают автодополнение оболочки. Пишите команды в ASCII; именно поэтому в
  `alicesay` встроено «Включаю».
- Длинные команды, вставленные дважды подряд, склеиваются. Проверяйте приглашение
  оболочки, прежде чем вставлять следующую.

## llm-alice

- Его журнал — `/tmp/llm-alice.log`: каждая обработанная фраза, каждый ответ,
  какая модель его дала и каким сценарием он прочитан.
- `llm-alice ask` без аргументов проверяет ключ и сеть без участия голоса.
- «Нейросеть сейчас не отвечает» через несколько секунд значит, что модель не
  ответила даже после повторов; причина — в журнале (часто HTTP 503: модель
  перегружена).
- Как маршрутизируются фразы — см. [15](15-llm-alice.md).

## Отключение

```
chattr -R -i /data/jbl-autostart
touch /data/jbl-autostart/ytm-off       # ytm-alice больше не стартует при загрузке
touch /data/jbl-autostart/llm-off       # llm-alice больше не стартует при загрузке
chattr -R +i /data/jbl-autostart
```

Остановить сейчас: `systemctl stop ytm-alice.service` или `systemctl stop llm-alice.service`.
