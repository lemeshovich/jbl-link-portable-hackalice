# Усунення несправностей

[English](../en/13-troubleshooting.md) · **Українська** · [Русский](../ru/13-troubleshooting.md)

## Звуку немає зовсім, Аліса теж мовчить

Найчастіше скинулось підсилення кодека ([07](07-audio.md#баг-із-підсиленням-після-завантаження)).

```
amixer -c 0 cget numid=7 | grep "  : values="      # 524288 — норма, 64 — проблема
/data/ytm/bin/ipcclean dmix
systemctl restart linkplay.service                  # звучить сигнал JBL
```

Якщо це стається після кожного завантаження, щось досі використовує
`amixer sget` або `sset` для простого елемента `Master`.

## Bluetooth мовчить, Аліса в порядку

Завислі підключення `dmix`. Ті самі дві команди, що вище.

## Аліса безкінечно «думає»

Світлодіоди крутяться, слово активації ігнорується, музика приглушена. Відповідь
відкинули, а діалог її чекає:

```
/data/ytm/bin/alicesay ""
```

## Аліса безкінечно слухає

Світлодіоди світяться, як під час слухання:

```
/data/ytm/bin/alicesay ""; sleep 2; /data/ytm/bin/qcancel -f 170 -E
```

Якщо все ще зависла, перезапустіть лише голосову роль:

```
kill $(ps | grep "[m]aind --yiod" | awk '{print $1}')
```

`quasar_launcher2` підніме її за кілька секунд. Не вбивайте її раз за разом:
кілька падінь поспіль відправляють роль на карантин приблизно на десять хвилин.

## Голосові команди поводяться дивно

Спершу журнал — у ньому видно кожну зміну стану й кожну дію:

```
cat /tmp/ytm-voice.log
grep -E "wake word|intercepted|announce|speech sent|not picked up|restored" /tmp/ytm-voice.log
```

Потім `yiod.log` за той самий час, поки він не ротувався (хвилини):

```
grep -a "HH:MM:S" /data/quasar/daemons_logs/yiod.log*
```

## ytm-alice просить увійти після перезавантаження

`droproot_setup` скинув права на файл сесії на відмінні від 600. Юніт із
`30-ytm.sh` виправляє це перед кожним запуском; перевірте, що хук встановлено.

## Копіювання команд у PuTTY

- Кирилиця, вставлена в PuTTY, може прийти спотвореною, а деякі символи
  викликають автодоповнення оболонки. Пишіть команди ASCII; саме тому в
  `alicesay` вбудовано «Включаю».
- Довгі команди, вставлені двічі поспіль, склеюються. Перевіряйте запрошення
  оболонки, перш ніж вставляти наступну.

## llm-alice

- Його журнал — `/tmp/llm-alice.log`: кожна оброблена фраза, кожна відповідь,
  яка модель її дала і яким сценарієм її прочитано.
- `llm-alice ask` без аргументів перевіряє ключ і мережу без участі голосу.
- «Нейросеть сейчас не отвечает» через кілька секунд означає, що модель не
  відповіла навіть після повторів; причина — в журналі (часто HTTP 503: модель
  перевантажена).
- Як маршрутизуються фрази — див. [15](15-llm-alice.md).

## Вимкнення

```
chattr -R -i /data/jbl-autostart
touch /data/jbl-autostart/ytm-off       # ytm-alice більше не стартує при завантаженні
touch /data/jbl-autostart/llm-off       # llm-alice більше не стартує при завантаженні
chattr -R +i /data/jbl-autostart
```

Зупинити зараз: `systemctl stop ytm-alice.service` або `systemctl stop llm-alice.service`.
