# ytm-play

[English](../en/08-ytm-play.md) · **Українська** · [Русский](../ru/08-ytm-play.md)

Невеликий AAC-плеєр для цієї колонки, написаний тому, що прошивка не вміє
декодувати те, що віддає YouTube Music ([07](07-audio.md#що-прошивка-не-вміє-декодувати)).
Джерела: [ytm-play/ytm-play.c](../../ytm-play/ytm-play.c). Ліцензія: GPL-2.0, бо
до нього вкомпільовано faad2.

## Що він робить

```
http:// stream or local file ─► MP4 parser ─► faad2 (AAC) ─► ALSA (via dlopen)
```

- Вхід: звичайна URL-адреса `http://` або локальний файл. ytm-alice подає йому
  аудіо з локального ретранслятора на `127.0.0.1:18883`, тож TLS у плеєрі не
  потрібен.
- MP4: звичайні файли (`moov` перед `mdat`) і фрагментовані (`moof` з `mdat`;
  інші блоки, як-от `sidx`, пропускаються).
- Декодування: faad2, зібраний **без** прапорця DRM і скомпонований статично.
- Вивід: `libasound.so` завантажується через `dlopen`, тож бінарник не залежить
  від заголовків ALSA прошивки чи точної версії бібліотеки. Пристрій задається
  `-D` (на колонці — `ytmout`).

## Інтерфейс для ytm-alice

```
ytm-play [-v] [-g 0..100] [-D alsa-device] <url|file>
```

Стандартний вхід, по одній команді в рядку:

| Команда | Дія |
|---|---|
| `pause` / `resume` | пауза або продовження |
| `volume <0..1>` | програмне підсилення, щоб приглушувати музику, поки говорить Аліса |
| `stop` | зупинитись і вийти |

Стандартний вивід, по одному об'єкту JSON у рядку: `{"event":"playing"}`,
`paused`, `position`, `eos`, `error`.

`-g 0` відтворює беззвучно — зручно, щоб перевірити пристрій, нічого не чуючи.

## Коректне завершення

- Обробник сигналу одразу закриває мережевий сокет, тож читання, що зависло на
  загальмованому потоці, не тримає процес живим.
- Обробник `atexit` дограє й закриває PCM, тож слот `dmix` звільняється (див.
  [завислі підключення](07-audio.md#завислі-підключення-dmix)).

Результат побайтово збігається з бінарником із релізу.
