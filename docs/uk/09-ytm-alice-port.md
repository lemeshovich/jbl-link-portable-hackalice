# Порт ytm-alice

[English](../en/09-ytm-alice-port.md) · **Українська** · [Русский](../ru/09-ytm-alice-port.md)

[ytm-alice](https://github.com/SPAWNRYS-ban/ytm-alice) — клієнт YouTube Music для
колонок Яндекса, який слухає Алісу й перебирає на себе музичні команди. Він
написаний під новіші прошивки. Ця сторінка описує, як його запустили на quasar
3.21; [10](10-voice-control.md) докладно описує голосове керування.

## Бінарники

| Файл | Що |
|---|---|
| `ytm-alice` | демон і CLI, Go, зібраний із патчем з `patches/` |
| `ytm-alice-resolver` | допоміжна програма на QuickJS-ng, що розшифровує адреси потоків, статична |
| `ytm-alice-player` | обгортка на shell, див. [device/ytm/ytm-alice-player](../../device/ytm/ytm-alice-player) |
| `ytm-play` | власне плеєр, див. [08](08-ytm-play.md) |

Усі чотири йдуть у `/data/ytm/bin/`. Конфіг ALSA — у `/data/ytm/my.conf`.

ytm-alice запускає `ytm-alice-player` зі свого каталогу з адресою
`http://127.0.0.1:18883/audio/...`; обгортка задає `ALSA_CONFIG_PATH` і запускає
`ytm-play -D ytmout`. GStreamer прошивки не використовується зовсім.

Збірка: [patches/build-ytm-alice.sh](../../patches/build-ytm-alice.sh) клонує
ytm-alice на коміті `923e9acc2517184c447853e00e96eb600f5cef94`, накладає
[патч](../../patches/ytm-alice-quasar-3.21.patch) і збирає обидві програми
(Go 1.27.3, `arm-linux-gnueabihf-gcc` 13.3.0 для resolver, UPX 4.2.2). Результат
побайтово збігається з бінарниками з релізу.

## Перший запуск

```
cd /data/ytm/bin
./ytm-alice login tv          # друкує код і адресу, де його ввести
./ytm-alice daemon start
./ytm-alice status
```

Вхід через TV не спливає, як сеанс браузера. Веб-панель — на порту 24721, а
колонка з'являється як ціль трансляції з назвою «Яндекс Станция».

## Власні голосові команди

У веб-панелі є список власних голосових команд: фраза малими літерами й дія. Патч
додає дію **Мои лайки** (`liked` у `settings.json`), щоб, наприклад,
`включи музыку` вмикало лайки. Без неї голе «включи музыку» не належить
ytm-alice, і Аліса відповідає, що потрібна підписка Плюс.

## Автозапуск

[device/jbl-autostart/hooks.d/30-ytm.sh](../../device/jbl-autostart/hooks.d/30-ytm.sh)
записує `ytm-alice.service` у `/run/systemd/system` і запускає його, не чекаючи.
Юніт:

- запускається після `linkplay.service` і мережі;
- спершу виконує `chmod 600` для файлів у `/data/yam/var/local.ytm-alice/`, бо
  ytm-alice відмовляється від файлу сесії з правами, відмінними від 600, а
  `droproot_setup` скидає їх при кожному завантаженні («файл сессии должен иметь
  права 600»);
- запускає демон без жодної затримки. Затримки ніколи не були рішенням
  ([03](03-persistence-and-autostart.md#тиша-після-завантаження-яка-не-стосувалась-автозапуску)).

## Що змінює патч

Відносно коміту `923e9acc` в upstream, у `main.go`, `ipc.go`, `cast.go`,
`playback_options.go`, `settings.go` і `web/app.js`, плюс файл тестів.
Усе, що стосується конкретної прошивки, вмикається лише тоді, коли `maind` не
містить `AliceCapability` (або коли задано `YTM_ALICE_SPEECH=server_action`), тож
новіші прошивки зберігають початкову поведінку.

| Зміна | Навіщо |
|---|---|
| Переносити розпізнаний текст із кадру стану 1 у кадр стану 3 без тексту | інакше на 3.21 жодна голосова команда не розпізнається |
| Говорити через `vins_server_action` + `repeat_after_me` | мовлення через `AliceCapability` на 3.21 немає; повертає «Включаю» і «что сейчас играет» |
| Відкидати відмову Аліси за її текстом у стані 3 через `cleanup_directive_controller`, потім звільняти діалог | на кожну перехоплену команду хмара відповідає «видео не поддерживается» або «нужна подписка» |
| Глушити лише Алісу (`ShadowMaster`), поки команда перехоплюється | відкинута відповідь іноді ще кілька сотень мс доходить до динаміка |
| Надсилати оголошення лише після того, як відмову відкинуто, і повторити раз, якщо Аліса його не підхопила | скасування скасовує й запит у дорозі; одразу після скасування `aliced` іноді ігнорує один запит |
| Закривати мікрофон, що сам відкривається після наших запитів | інакше Аліса слухає близько 5 с, і музика лишається приглушеною |
| Тримати IPC-з'єднання відкритими 0,5 с після запису | `aliced` губить повідомлення з'єднань, що закриваються зарано |
| Повторена фраза — нова команда, якщо між ними було слово активації | «дальше» двічі за 10 с ігнорувалось як дубльований кадр |
| Читати й задавати гучність через елемент регулятора `Master` замість `amixer sget/sset Master` | доступ через простий мікшер глушить колонку після завантаження ([07](07-audio.md#баг-із-підсиленням-після-завантаження)) |
| Без оголошення на «дальше» / «назад» | upstream оголошує й при зміні треку |
| `/tmp/ytm-voice.log` | журнал станів Аліси й кожної дії, невеликий і з ротацією |
| Дія «Мои лайки» для власних голосових команд (`liked`) | дає змогу фіксованій фразі, як-от голе «включи музыку», вмикати лайки замість «нужна подписка» від Аліси |

Тести для розбору кадрів, розпізнавання відмов і «воріт» оголошення — у
`legacy_voice_test.go`; набір тестів upstream проходить.
