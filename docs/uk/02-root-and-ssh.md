## Root через ADB

Під час завантаження прошивка ненадовго відкриває USB ADB. Якщо під час старту
колонки підключено USB-C, кілька секунд доступна root-оболонка:

```
adb wait-for-usb-device shell "touch /tmp/lock_activated_adb && ..."
```

`/tmp/lock_activated_adb` не дає `maind` знову закрити USB ADB до наступного
перезавантаження. `/data/network_adb` змушує `adbd` слухати ще й TCP 5555 — саме
так було отримано перший доступ по мережі. Скрипт `enable-adb.sh` з PR створює ці
маркери й захищає їх `chattr +i`.

Мережевий ADB — це root-оболонка без автентифікації для всієї локальної мережі.
Коли запрацює SSH, приберіть його: зніміть `chattr -i` з `/data/network_adb` і
видаліть файл. USB ADB під час завантаження лишається як запасний вхід.

## SSH

Dropbear працює як сервер лише з входом за ключем на порту 2222, з
`/data/jbl-ssh/`:

- зібраний статично з musl за допомогою Zig, без автентифікації за паролем і PAM:
  [device/ssh/build-dropbear.sh](../../device/ssh/build-dropbear.sh);
- запускається при завантаженні скриптом `ssh-service.sh` з PR через хук
  `10-ssh.sh`, який пише тимчасовий юніт systemd у `/run`;
- усе дерево `/data/jbl-ssh` захищене `chattr -R +i`, тож `droproot_setup` не може
  послабити права на ключі.

Використовуйте окрему пару ключів ed25519 і зберігайте резервну копію ключа хоста
поза пристроєм. Скрипт `install-ssh.sh` з PR виконує ці кроки з перевірками; на
цій прошивці ті самі кроки зроблено вручну.

## Передача файлів без scp

Dropbear тут без підсистеми SFTP. Два способи, що працюють із `cmd` у Windows:

```
type file | ssh -p 2222 root@<колонка> "cat > /data/path/file"
```

і, для всього, що має пережити копіювання через буфер обміну, base64:

```
type file.b64 | ssh -p 2222 root@<колонка> "base64 -d > /data/path/file"
```

Завжди порівнюйте `sha256sum` з обох боків, перш ніж використовувати бінарник.
