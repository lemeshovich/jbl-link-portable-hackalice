## Root через ADB

Під час завантаження прошивка на кілька секунд відкриває USB ADB. Якщо в цей
момент колонка підключена кабелем USB-C, можна отримати оболонку root:

```
adb wait-for-usb-device shell "touch /tmp/lock_activated_adb && ..."
```

Файл `/tmp/lock_activated_adb` не дає `maind` закрити USB ADB до наступного
перезавантаження. А файл `/data/network_adb` змушує `adbd` слухати ще й TCP-порт
5555 — так ми вперше дісталися колонки по мережі. Обидва маркери створює скрипт
`enable-adb.sh` з PR і захищає їх через `chattr +i`.

Пам'ятайте, що мережевий ADB — це root без жодного пароля для всіх у вашій
мережі. Щойно запрацює SSH, його варто прибрати: зняти `chattr -i` з
`/data/network_adb` і видалити файл. USB ADB при завантаженні нікуди не дінеться
— це ваш запасний вхід.

## SSH

На порту 2222 працює Dropbear, пустить лише за ключем. Лежить він у
`/data/jbl-ssh/`:

- зібраний статично з musl за допомогою Zig, вхід за паролем і PAM вимкнені ще
  при збиранні: [device/ssh/build-dropbear.sh](../../device/ssh/build-dropbear.sh);
- стартує при завантаженні через скрипт `ssh-service.sh` з PR, який викликає
  хук `10-ssh.sh` і створює тимчасовий юніт systemd у `/run`;
- увесь каталог `/data/jbl-ssh` захищений `chattr -R +i`, тож `droproot_setup`
  не зможе послабити права на ключі.

Заведіть для колонки окрему пару ключів ed25519, а ключ хоста збережіть десь
поза колонкою. Скрипт `install-ssh.sh` з PR робить усе це з перевірками; на нашій
прошивці ми пройшли ті самі кроки вручну.

## Як передавати файли без scp

SFTP у цьому Dropbear немає. З `cmd` у Windows працюють два способи. Звичайний:

```
type file | ssh -p 2222 root@<колонка> "cat > /data/path/file"
```

І через base64, якщо файл має пройти через буфер обміну без пошкоджень:

```
type file.b64 | ssh -p 2222 root@<колонка> "base64 -d > /data/path/file"
```

Перш ніж запускати бінарник, звірте `sha256sum` на ПК і на колонці.
