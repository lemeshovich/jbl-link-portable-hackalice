# Нотатки з дослідження заліза

[English](../en/14-hardware-research.md) · **Українська** · [Русский](../ru/14-hardware-research.md)

Нотатки для тих, хто хоче піти далі, наприклад замінити Алісу локальним голосовим
стеком. Нічого з цього поточна конфігурація не використовує.

## Мікрофони

- Пристрій запису `hw:0,1` (Wake on Voice, `pcmC0D1c`), `S32_LE`, 16000 Гц, два
  канали, period 1000, buffer 8000.
- Його тримає відкритим `maind`, тож інша програма не може записувати, поки
  працює квазар.

## Петля відтворення

- `hw:0,5` (AWB_Record) записує те, що відтворює колонка, а не мікрофони. Корисно,
  щоб записати вивід або як опорний сигнал для придушення відлуння.

## Регулятори гучності

| Регулятор | numid | Діапазон | Примітки |
|---|---|---|---|
| `Master` | 128 | від 0 до 999 | softvol, його рухають кнопки |
| `ShadowMaster` | 120 | від 0 до 999 | softvol для `default`, голос Аліси |
| `Digital Playback Volume` | 18 | від 0 до 255 | типово `207,207` |
| `HW Gain1 Volume` | 7 | у нормі 524288 | встановлює Linkplay при старті; див. [07](07-audio.md) |

## Світлодіоди

У `/sys/class/leds/` є `power-white`, `red`, `white1`…`white5` і `wifi`.
`white1`…`white5` — це **індикатор заряду ззаду**, а не кільце спереду.

Переднім кільцем (фіолетове, коли Аліса слухає, крутиться, коли думає, синє для
Bluetooth, червоне при вимкнених мікрофонах) керує сам квазар через
`/dev/i2c-led`, який тримає відкритим `maind`. Його протокол невідомий, і IPC-
повідомлення для керування ним немає; єдине повідомлення `QuasarMessage` про
світлодіоди, `led_screen_command` (180), призначене для захоплення екрана. Писати
в пристрій паралельно з квазаром — ризик збити його стан.

## Linkplay

`linkplay.sh` налаштовує маршрутизацію кодека через `amixer` (перемикачі на кшталт
`O03 I05`, `I2S O03_O04`, `AmpSwitch`), а потім запускає `rootApp`. Повторний
запуск лише цих рядків `amixer` **не** повертає звук; підсилення пізніше задає сам
старт Linkplay.
