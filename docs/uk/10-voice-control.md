# Голосове керування на старій прошивці

[English](../en/10-voice-control.md) · **Українська** · [Русский](../ru/10-voice-control.md)

Що відбувається між «Алиса, включи на ютубе Daft Punk» і першими звуками музики
на quasar 3.21 і навіщо потрібен кожен крок. Усе описане ми бачили в голосовому
журналі (`/tmp/ytm-voice.log`) та в `yiod.log`, а не вигадали.

## У чому проблема

Аліса відправляє кожну команду в хмару. ytm-alice бачить розпізнаний текст і сам
вмикає музику, але хмара теж відповіла, і Аліса от-от скаже «Воспроизведение
видео не поддерживается на этом устройстве» або «Для этого нужна подписка
Плюс…». На новіших прошивках ytm-alice перериває її через `AliceCapability`, а на
3.21 такого механізму немає.

## Що не допомогло

- Скасовувати діалог одразу, щойно команду розпізнано. Відповідь приходить
  пізніше, тож у цей момент скасовувати ще нічого.
- Скасовувати кілька секунд поспіль. Так закривається й мікрофон, і наступна
  команда обривається на півслові.
- Підмінювати відповідь порожнім «повтори за мною». Цей запит іде через хмару
  0,3–2 секунди, і за цей час Аліса встигає сказати перші слова.
- Повідомлення прошивки, схожі на скасування (`restart_vins_dialog`,
  `sound_cancel`, кнопка дії). На 3.21 вони ні на що не впливають.

## Що допомогло

### 1. Розпізнати команду

Текст приходить у кадрі зі станом 1, а остаточний стан 3 — окремим кадром, без
тексту. Тож текст запам'ятовуємо й переносимо (не довше ніж на 10 секунд).
Повторена фраза вважається новою командою, якщо між ними прозвучало «Аліса».

### 2. Заглушити тільки Алісу

У цю мить зберігаємо значення `ShadowMaster` (це гучність Аліси) і ставимо його в
нуль. Музика йде через `Master` і грає далі. Збережене значення пишемо у файл
`/tmp/ytm-shadow-saved`, тож якщо демон впаде, поки Аліса заглушена, після
перезапуску він поверне їй голос.

### 3. Прибрати відповідь ще до того, як вона прозвучить

Відповідь з'являється в кадрі зі станом 3 разом із текстом — раніше, ніж Аліса
почне говорити:

```
state 3 -> 3 speech="Воспроизведение видео не поддерживается на этом устройстве."
refusal in state 3 ...: cleanup_directive_controller
state 3 -> 0
```

Відмовою вважаємо відповідь, у якій є «подписк», «видео», «не поддерживается» чи
«недоступ», і лише протягом 12 секунд після команди, яку перехопив ytm-alice. Так
Алісу не заглушать, коли її питають про щось зовсім інше.

`cleanup_directive_controller` — штатне скасування діалогу. Буває, що відповідь
уже потрапила в звуковий тракт, і Аліса ще до двох секунд «говорить» у
заглушений канал. Тому глушіння тримаємо, поки вона в стані 2 з відмовою, але
загалом не довше 4 секунд.

### 4. Розблокувати діалог

Коли відповідь прибрано, діалог чекає на відтворення, яке вже ніколи не почнеться:
світлодіоди крутяться, ніби Аліса думає, а на «Аліса» вона не реагує.
Розблоковує діалог наступний запит. Для «включи» це саме «Включаю», а для
«пауза», «дальше» та інших — порожнє «повтори за мною», на яке Аліса відповідає
мовчанням.

### 5. Повернути голос і сказати «Включаю»

`ShadowMaster` повертаємо приблизно через 400 мілісекунд після того, як відмову
прибрано (або через 2,5 секунди після команди, якщо відмови не було). І лише тоді
надсилаємо «Включаю», бо скасування зачіпає й запит, який уже в дорозі. Якщо за
1,5 секунди Аліса не відреагувала (зазвичай вона встигає за 50 мілісекунд),
надсилаємо ще раз.

### 6. Закрити мікрофон

Після кожного нашого запиту прошивка сама відкриває мікрофон секунд на п'ять, і
весь цей час музика приглушена. Якщо Аліса перейшла в стан 1 протягом 10 секунд
після нашого запиту і **перед цим** не було «Аліса», демон через секунду
надсилає `cleanup_directive_controller` і повторює, поки вона слухає. А от
розмову, яку ви самі почали з «Аліса», це не зачіпає: там спершу завжди приходить
подія слова активації.

## Як це виглядає в журналі

```
wake word
state 0 -> 1
state 1 -> 3
ShadowMaster 610,610 -> 0 (Alice muted)
intercepted "Включи на YouTube Daft Punk" -> play
state 3 -> 3 speech="Воспроизведение видео не поддерживается на этом устройстве."
refusal in state 3 ...: cleanup_directive_controller
state 3 -> 0
ShadowMaster restored to 610,610
announce queued "Включаю" (attempt 0)
speech sent after 4ms "Включаю" err=<nil>
state 0 -> 3
state 3 -> 2 speech="Окей, повторяю за вами: «Включаю»."
state 2 -> 1
auto-listen opened after our request
auto-listen still open: cleanup_directive_controller
state 1 -> 0
```

## Якщо Аліса все ж зависла

- **Думає без кінця** — світлодіоди крутяться, на «Аліса» не реагує:
  `alicesay ""` розблокує діалог.
- **Слухає без кінця**: `alicesay ""`, потім `qcancel -f 170 -E`. Якщо не
  допомогло, перезапустіть голосову роль:
  `kill $(ps | grep "[m]aind --yiod" | awk '{print $1}')`. Лаунчер підніме її за
  кілька секунд.
