# Якщо щось пішло не так

[English](../en/12-troubleshooting.md) · **Українська** · [Русский](../ru/12-troubleshooting.md)

## Немає звуку взагалі, Аліса теж мовчить

Найчастіше це скинуте підсилення кодека
([розділ 07](07-audio.md#підступне-підсилення-після-завантаження)).

```
amixer -c 0 cget numid=7 | grep "  : values="      # 524288 — норма, 64 — проблема
/data/ytm/bin/ipcclean dmix
systemctl restart linkplay.service                  # пролунає сигнал JBL
```

Якщо це повторюється після кожного завантаження, значить, щось досі звертається
до `Master` через `amixer sget` або `sset`.

## Bluetooth мовчить, а Аліса говорить

Зависли підключення до `dmix`. Допомагають ті самі дві команди, що вище.

## Аліса «думає» без кінця

Світлодіоди крутяться, на «Аліса» вона не реагує, музика приглушена. Значить,
відповідь прибрали, а діалог досі на неї чекає:

```
/data/ytm/bin/alicesay ""
```

## Аліса слухає без кінця

Світлодіоди горять, як під час слухання:

```
/data/ytm/bin/alicesay ""; sleep 2; /data/ytm/bin/qcancel -f 170 -E
```

Не допомогло — перезапустіть лише голосову роль:

```
kill $(ps | grep "[m]aind --yiod" | awk '{print $1}')
```

`quasar_launcher2` підніме її за кілька секунд. Тільки не робіть цього раз за
разом: після кількох падінь поспіль лаунчер відкладає роль приблизно на десять
хвилин.

## Голосові команди поводяться дивно

Спершу дивимося журнал — у ньому кожна зміна стану й кожна дія:

```
cat /tmp/ytm-voice.log
grep -E "wake word|intercepted|announce|speech sent|not picked up|restored" /tmp/ytm-voice.log
```

Потім `yiod.log` за той самий час, поки його не перезаписало (а це лічені
хвилини):

```
grep -a "HH:MM:S" /data/quasar/daemons_logs/yiod.log*
```

## ytm-alice просить увійти після перезавантаження

`droproot_setup` змінив права на файл сесії, а ytm-alice приймає лише 600. Юніт,
який ставить `30-ytm.sh`, виправляє це перед кожним запуском, тож перевірте, чи
хук на місці.

## Команди в PuTTY

- Кирилиця, вставлена в PuTTY, може прийти зіпсованою, а деякі символи ще й
  запускають автодоповнення. Пишіть команди латиницею — саме тому «Включаю»
  вшито в `alicesay`.
- Якщо вставити дві довгі команди поспіль, вони склеюються. Перед наступною
  дочекайтеся запрошення оболонки.

## llm-alice

- Журнал — `/tmp/llm-alice.log`. У ньому кожна оброблена фраза, кожна відповідь,
  яка модель її дала і яким сценарієм Аліса її прочитала.
- `llm-alice ask` без аргументів перевіряє ключ і мережу, не задіюючи голос.
- Якщо за кілька секунд Аліса каже «Нейросеть сейчас не отвечает», модель не
  відповіла навіть після повторів. Причину шукайте в журналі; найчастіше це
  HTTP 503 — модель перевантажена.
- Як вирішується, кому відповідати, — у [розділі 14](14-llm-alice.md).

## Як усе вимкнути

```
chattr -R -i /data/jbl-autostart
touch /data/jbl-autostart/ytm-off       # ytm-alice більше не стартує при завантаженні
touch /data/jbl-autostart/llm-off       # llm-alice теж
chattr -R +i /data/jbl-autostart
```

Зупинити просто зараз: `systemctl stop ytm-alice.service` або
`systemctl stop llm-alice.service`.
